## [1.0.3] — 2026-09-17

### Изменено
- Вечерний выпуск, шлюз 3: две проверенные судьёй строки публикуются независимо от доли отброшенных; одна строка при большинстве отброшенных и ноль строк — не выходят (17.09 выпуск с двумя проверенными строками не вышел из-за «отброшено 4 из 6»). `evening.gate3_reasons`, тесты.

## [1.0.2] — 2026-09-17

### Изменено (без изменения текста выпусков)
- `radarlog.py` — общий журнал для `radar.py` и `evening.py`; ленивый импорт `radar` ради `log` из `evening` убран (цикл radar↔evening).
- `gate.finalize` — одна точка «вёрстка → термины → шлюз» перед каналом и сайтом для утренней сводки и вечернего выпуска
  (раньше три шага были расписаны в двух местах); `publish.fit` — одна обрезка по границе строки вместо двух копий.
- `evals/publish_test.py` в CI: путь публикации без сети — лимиты подписи и сообщения, отказ от обрезки и моджибейка,
  журнал опубликованного, `tidy`, `fit`, `finalize`.

## [1.0.1] — 2026-09-17

### Исправлено
- Недельный лимит разборов считался по записям журнала, а не по дням: три поста и черновики 10.09 дали «7/3», и с 14 по 17.09
  разбор по инфоповоду не выходил. Теперь считаются дни с разбором за 7 дней (`digest.essays_this_week`, тест `evals/daily_test.py`).
- `crontab.txt` приведён к живому расписанию (утро 09:00 и вечер 20:00 МСК каждый день, сбор 05:20, evals 10:00, чистка вс 04:00).

### Добавлено
- `tools/` — одноразовые скрипты правок постов 11–12.09 сохранены в репозитории как история.

## [1.0.0] — 2026-09-17

Первая версия, которой присвоен номер: всё, что накопилось с 09.09.2026 до PR #8.

### Выпуски
- Утренняя сводка каждый день в 09:00 МСК: изменения условий у 12 банков (34 страницы), новости по одному событию на строку,
  раздел «Банк России» в день решения по ставке, акции банков буквально (без модели), тихий день без вызова модели.
- Тематический разбор только по инфоповоду (изменение ценового параметра), не чаще трёх в неделю, с окном на «стоп» через Джарвиса.
- Вечерний выпуск в 20:00 МСК: первоисточник вместо репоста, 2–3 факта из статьи, «что это значит», «Главное» по весу темы
  для розничного кредитора (`digest.npv_weight`), строки без факта и без смысла не выходят.
- Страница каждого выпуска на сайте (архив, RSS, sitemap, IndexNow) из того же текста, что в канале.

### Источники
- Сайты банков (GET, при JS-заглушке — браузер), RSS прессы, новости и ключевая ставка ЦБ, пресс-релизы БКИ (НБКИ, ОКБ,
  Скоринг Бюро), публичные Telegram-каналы, котировки Мосбиржи; тарифные документы — для приватных разборов.

### Шлюз публикации (`gate.py`, `digest.check`, `style.py`)
- Реклама (erid, промо-utm), строка без источника, повтор уже опубликованного (новость 7 дней, ставка до изменения, тикер 7 дней) — не проходят.
- «Было X, стало X», общий элемент сайта на нескольких продуктах, ставка вклада как ставка по кредиту, «до X %» ниже ключевой + 3 п.п. — не проходят.
- Неполная страница (< 70 % строк прошлого снимка), мигание вёрстки (строка не во всех из 7 снимков), cookie-баннеры и чат-боты — не считаются изменением.
- Строки модели с числом, которого нет в данных, отбрасываются; слово «конкурент» и упоминание своего банка запрещены.

### Инфраструктура
- Приватный репозиторий — источник правды; main защищён; ветка → PR → CI (compileall, gate_test, evening_test) → merge → деплой на VPS из Actions.
- Evals: снимок каждого выпуска (`evals/days/`), рубрика d1–d9/e1–e5, судья Sonnet 5 по будням, метрики на сайте.
- Учёт расходов на модель (`state/costs.jsonl`), бюджетный страж, дешёвые модели по умолчанию.
- Публичное зеркало `nikita-ageev/credit-radar` (белый список файлов, санитизация).
